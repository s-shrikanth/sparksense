# SparkSense journal submission manuscript

This directory contains the current nine page Springer Electrical Engineering submission manuscript and its figure assets. The cover letter and journal selection note are included for submission planning.

The manuscript presents SparkSense as a disturbance aware motor condition monitoring framework that integrates AC and DC motor profiles, operating context, acquisition validity, local decisions, outage tolerant records, measured vibration corroboration, and a gated product development route.

Build from this directory with:

```bash
pdflatex SparkSense_Enhanced_Manuscript.tex
pdflatex SparkSense_Enhanced_Manuscript.tex
```

The evidence sources remain identified accurately in the methods and limitations. The budget ranges are engineering planning estimates and are not supplier quotations.
